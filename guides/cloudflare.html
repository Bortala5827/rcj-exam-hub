Cloudflare 注册与 Pages 部署

Cloudflare Pages 能免费把静态网站部署成全球可访问的网址，自带 CDN 加速。它支持两种常见方式：连接 GitHub 仓库自动部署，或者直接上传文件（无需 Git）。

一、注册 Cloudflare 账号

  1. 打开官网

    访问 cloudflare.com，点右上角 "Sign up"（注册）。

  2. 用邮箱注册

    填邮箱 + 设置密码，免费版足够个人使用，无需绑卡。

  3. 验证邮箱

    查收验证邮件并点击确认，登录后台（Dashboard）。

二、两种部署方式，怎么选

  • 连接 GitHub 仓库：适合准备长期维护、想自动同步代码的人。以后每次改完代码 push，Pages 都会自动重新部署。
  • 直接上传文件：适合只想快速上线、暂时不想学 Git 的人。把本地文件夹拖进 Cloudflare 即可，无需仓库。

第一次建站建议先用「直接上传」把页面跑起来；熟悉后再切到 GitHub，自动部署更省心。

三、方式一：连接 GitHub 仓库

这种方式需要先把网站文件放到 GitHub。如果你还没建仓库，先看 GitHub 注册与仓库管理。

  1. 进入 Pages

    在 Cloudflare 后台左侧菜单找到 Workers & Pages 点 Create 选 Pages 标签页。

  2. 连接 Git

    点 Connect to Git，授权 Cloudflare 访问你的 GitHub，然后选中刚才建好的仓库。

  3. 首次授权

    按提示在 GitHub 弹窗里点 "Authorize Cloudflare"，允许它读取你的仓库。

  4. 配置构建（静态站重点）

    纯静态站点（HTML/CSS/JS，不需要 npm 构建）按下面填：

    • Framework preset：选 None（无框架）。
    • Build command：留空（不用敲任何命令）。
    • Build output directory：首页在仓库根目录就填 /；若放在子目录（如 docs/）就填对应目录名。

    不要随手选了某个框架（如 React/Vite），否则它会去跑 npm build，找不到配置就会部署失败。纯 HTML 站一律选 None。

  5. 开始部署

    点 Save and Deploy，等 1–2 分钟，状态变绿即成功。你会得到一个 xxx.pages.dev 免费网址。

四、方式二：直接上传文件

不需要 Git，直接把本地文件夹拖进 Cloudflare 即可上线。

  1. 进入上传入口

    在 Cloudflare 后台打开 Workers & Pages Create 选 Pages 点 Upload assets（上传资源）。

  2. 命名项目

    给项目起一个名字（如 my-first-site），这个名字会出现在你的免费网址里。

  3. 上传文件夹

    把包含 index.html 的文件夹整个拖拽到上传区域，或点上传按钮选择文件夹。等待上传完成。

  4. 拿到网址

    上传完成后 Cloudflare 会自动部署，几秒到几分钟后给你一个 xxx.pages.dev 网址，点开后即可访问。

重新上传时，进入项目 Deployments Upload assets，拖入新的文件夹即可覆盖上线。对命令行熟悉的用户也可以用 Wrangler CLI 的 wrangler pages deploy 直接推。

五、（可选）绑定自己的域名

两种方式部署完成后，都可以在 Pages 项目里点 Custom domains 添加你的域名，按提示去域名商后台加一条 CNAME 解析。没有域名也能用 .pages.dev 免费跑，不影响已上线内容。

六、之后如何更新

  • GitHub 方式：在 GitHub 里改文件并提交，Cloudflare 会自动重新部署。
  • 直接上传方式：进入项目重新上传整个文件夹覆盖旧版本。
  • 浏览器看旧版？按 Ctrl+F5（Mac：Cmd+Shift+R）强制刷新。

Cloudflare Pages 免费版对单个文件有 25MB 上限。上传前请确认没有超大 PDF/视频，否则整次部署会失败。
