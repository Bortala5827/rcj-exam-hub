零成本搭建你的个人站点

本篇把前面三课串起来：把你的内容（题目、作品、个人介绍）整理成数据，生成可在线访问的网页，再免费部署上线。整套成本为 0——可以是刷题资料站，也可以是个人作品集、名片式展示页，套路完全一样。

  3. 第二步：生成网页

  5. 第四步：分享与合规提醒

一、这套方案在做什么

核心思路就三步：内容（数据） 模板（网页） 托管（免费平台）。你只负责准备内容，网站结构和上线流程都可以复用现成方案，不必从头写代码。

同一个流水线能产出很多种站点，举几个例子：

  • 刷题 / 资料站：把题库变成"在线答题、错题复盘"的界面。
  • 个人作品集：把你的设计、写作、项目截图排成好看的画廊。
  • 名片式展示页：一句话介绍 + 联系方式 + 社交链接，当成线上简历。
  • 服务 / 店铺介绍页：展示你提供的服务、价格、购买入口。

二、第一步：整理你的内容

先把要展示的东西规整成"机器好读"的格式。最简单的做法是建一张表或一份清单，每条内容字段一致。

下面以"刷题站"为例给出字段；做个人展示页时，把同样的结构换成"板块名 / 标题 / 正文 / 图片路径"即可，逻辑一模一样。

刷题站示例（题库表）

题型, 题目, 选项A, 选项B, 选项C, 选项D, 答案, 解析 单选, 下列属于行政处罚的是？, 拘役, 罚款, 管制, 有期徒刑, B, 罚款属行政处罚…… 判断, 辅警可以单独执法。, , , , , 错, 辅警须在民警带领下开展工作。

个人展示页示例（板块清单）

板块, 标题, 正文, 图片 关于我, 你好，我是小明, 一名前端爱好者，擅长……, images/me.jpg 作品, 刷题小工具, 用 HTML 做的离线刷题页, images/work1.jpg 联系, 找我合作, 微信 / 邮箱,

没有 Excel 也没关系，用记事本按"标题 == 内容"一行一条写也行；重点是每条的字段要一致，方便后续导入或让 AI 读取。

注意版权与隐私：自己整理的内容、原创作品可以放心用；直接搬运他人付费资料再分发可能侵权，他人照片/个人信息未经授权也不要公开。

三、第二步：生成网页

两条路，任选其一：

路线 A：用 AI 工具生成（零基础推荐）

  1. 把内容给 AI

    按 AI 桌面工具建站 的方法，把上面的表格 / 清单粘贴给 WorkBuddy / Trae / Qoder。

  2. 下达指令

    说："请根据这份内容生成一个【刷题站 / 个人作品集 / 展示页】，支持【在线答题 / 画廊浏览 / 联系方式】，输出单个 index.html。"

  3. 预览微调

    生成后本地打开，用大白话让它改配色、加板块、调手机端样式。

路线 B：用现成模板

  • 找开源的静态站模板（如 rcj-exam-builder 这类思路），按其说明把内容填进去。
  • 优势是结构成熟、功能全；劣势是要稍微看懂它的配置方式。

四、第三步：免费部署上线

拿到最终 index.html（和需要的图片 / 资源）后：

  1. 存到 GitHub

    两条路任选：

    • 网页小白版：按 GitHub 教程 直接拖拽上传。
    • AI 工具版（推荐）：在 WorkBuddy / Trae / VS Code 里执行 git init git add . git commit git push origin main，直接推送到 GitHub。详见 更快：用 WorkBuddy / Trae 直接推送。

  2. 连 Cloudflare 部署

    按 Cloudflare 教程 连接仓库、选 None 框架、部署，拿到网址。

  3. 验证

    打开网址，手机和电脑各刷一遍，确认内容正常显示、交互正常。

五、分享与合规提醒

  • 引流思路：免费站点本身可以当"橱窗"吸引访客，再引导到你的完整版 / 付费服务或联系方式。
  • 诚实第一：站点展示的能力要真能实现，避免夸大导致信任损耗。
  • 合规底线：不碰他人版权资料、不公开他人隐私、不诱导站外违规交易。
  • 可选进阶：如果后续需要跑后端或完全掌控，可再考虑 自己买域名 + 服务器。
