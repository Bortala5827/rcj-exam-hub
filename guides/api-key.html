免费 API Key 申请教程

本站 AI 点评、语音转写走「前端 + 你自己的 Key」模式，Key 只存你浏览器本地。下面手把手教你免费申请。

省事方案：硅基流动一个 Key 同时搞定语音转写 + AI 对话，新手首推。更多平台见 API 汇总页。

一、通用拿 Key 步骤

所有平台流程都一样，掌握一套通吃：

  1. 注册登录

    手机号注册（部分支持微信/邮箱）。

  2. 找到 API 密钥

    左侧菜单找「API 密钥 / API Key / 访问控制」。

  3. 创建并复制 Key

    点「新建密钥」，生成后立刻复制（通常只显示一次，形如 sk-xxxx）。

  4. 确认免费额度

    新用户一般送体验金，或部分模型直接免费档。

二、硅基流动 SiliconFlow

同时支持语音转写和对话，一个 Key 覆盖大多数需求。

  1. 注册

    访问 cloud.siliconflow.cn，手机号注册送体验额度。

  2. 创建 Key

    左侧「API 密钥」「新建密钥」，生成后立刻复制。

  3. 记下参数

    Base URL：https://api.siliconflow.cn/v1
    转写模型：FunAudioLLM/SenseVoiceSmall
    对话模型：deepseek-ai/DeepSeek-V4-Flash

三、DeepSeek

高质量对话/推理，支持多模态看图。不支持语音转写，转写走硅基流动。

  1. 注册

    访问 platform.deepseek.com，手机号注册送体验额度。

  2. 创建 Key

    左侧「API keys」「Create API key」，生成后立刻复制。

  3. 记下参数

    Base URL：https://api.deepseek.com/v1
    模型：deepseek-v4-flash（日常）/ deepseek-v4-pro（强推理）

四、填进工具

核心三项：Base URL + Key + 模型名。

方案 A：硅基流动（一个 Key 全包）

API Base URL：https://api.siliconflow.cn/v1 AI 点评模型：deepseek-ai/DeepSeek-V4-Flash 语音转写模型：FunAudioLLM/SenseVoiceSmall API Key：你的硅基流动 Key

方案 B：DeepSeek（仅对话，转写另配）

API Base URL：https://api.deepseek.com/v1 模型名：deepseek-v4-flash API Key：你的 DeepSeek Key

填完点「测试连接」验证。适用：深圳辅警、惠州辅警、SoloSpeak。

五、常见问题

  • 401 / Key 无效：复制带进了空格，或额度用完。重新复制完整 Key。
  • 404：接口地址拼错，多/少了 /v1。
  • 担心泄露：Key 仅存你浏览器。去平台「删除密钥」即可让旧 Key 失效。
  • 更多平台：Kimi、智谱、MiMo 等见 API 汇总页，申请流程一样。
