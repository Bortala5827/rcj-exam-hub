GitHub 注册与仓库管理

GitHub 相当于"代码的网盘 + 版本历史"。它不直接面向访客，而是给 Cloudflare 这类平台提供源头文件。本篇教你在网页上就能完成所有操作，无需装任何软件。

本篇目录
  1. 注册 GitHub 账号
  2. 创建仓库（Repository）
  3. 上传文件（网页拖拽法）
  4. 更快：用 WorkBuddy / Trae 直接推送（推荐）
  5. 提交（Commit）说明

  7. 仓库管理小技巧

一、注册 GitHub 账号

  1. 打开官网

    访问 github.com，点右上角 Sign up。

  2. 填信息

    输入邮箱、设密码、取一个用户名（英文/数字，以后仓库地址会带它）。

  3. 验证人机 + 邮箱

    完成拼图验证，再去邮箱点验证链接激活账号。

二、创建仓库（Repository）

  1. 新建仓库

    登录后点右上角 + New repository。

  2. 填仓库名

    Repository name 用英文名（如 my-site），它会成为地址的一部分，别用中文。

  3. 设为公开 + 初始化

    选 Public（公开，免费）；勾选 Add a README file 方便后面说明。最后点 Create repository。

仓库名只影响网址，不影响网站显示内容，可以随意取。

三、上传文件（网页拖拽法，最适合小白）

  1. 进入仓库

    打开你刚建的仓库主页。

  2. 上传

    点 Add file Upload files，把电脑里的 index.html（和图片文件夹）直接拖进虚线框。

  3. 等待上传完成

    文件列表里出现你的文件即成功，先别急着关页面。

如果用了图片，记得连图片文件夹一起上传，并保持代码里的路径一致（如 images/logo.png）。

四、更快：用 WorkBuddy / Trae 直接推送（推荐日常用）

如果你已经在 WorkBuddy、Trae、Cursor 或 VS Code 里让 AI 生成了网站，其实不用打开 GitHub 网页，直接本地提交推送最快：

  1. 初始化仓库

    在项目文件夹里执行：
    git init
    （Trae / VS Code 通常已在新建项目时自动建好 .git）

  2. 在 GitHub 网页创建一个空仓库

    只填仓库名、选 Public，不要勾选 Add README，点 Create。复制页面里形如 https://github.com/用户名/仓库名.git 的地址。

  3. 关联远端并推送

    git remote add origin https://github.com/你的用户名/仓库名.git git add . git commit -m "首次提交：上传网站" git push -u origin main

    第一次会弹窗让你登录 GitHub，授权后文件就全部上去了。

  4. 以后每次更新

    git add . git commit -m "更新说明" git push origin main

    推送后 Cloudflare Pages 会自动重新部署，几十秒就能在线上看到新版本。

如果你之前是在 GitHub 网页建的仓库，可以先用 git clone https://github.com/用户名/仓库名.git 把它下载到本地（Trae / VS Code 也有"克隆仓库"按钮），改完再 push，逻辑完全一样。

五、提交（Commit）说明

上传后页面底部有一个 "Commit changes" 区域，这是给这次改动写备注：

  • 在 Commit message 里写一句大白话，如 首次上传网站首页。
  • 直接点 Commit changes 即可，无需改其他选项。
  • 以后每次改文件，都用同样方式"上传 + 提交"，形成更新历史。

六、连接 Cloudflare Pages

文件存好后，让它变成可访问网站：

  • 打开 Cloudflare 注册与 Pages 部署 教程。
  • 在 "连接 Git" 步骤里授权并选中本仓库，即可一键部署。

七、仓库管理小技巧

  • 写好 README：仓库里的 README.md 是说明文档，写清楚这是什么站、怎么用。
  • 别传密钥/隐私：不要把账号密码、API Key 传进公开仓库。
  • 大文件另想办法：GitHub 单文件建议 ≤ 100MB，超大 PDF/视频更适合放网盘或对象存储。
  • 想搭建自己的站（刷题站 / 作品集 / 展示页）：见 零成本搭建你的个人站点。
