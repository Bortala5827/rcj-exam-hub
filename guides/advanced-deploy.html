高阶玩法：把站点挂到自己的域名下

前面的课你已经用 Cloudflare Pages 把站点免费上线了，地址形如 xxx.pages.dev。再往前走一步——花十几块钱买个自己的域名（如 yourname.xyz），就能让访客记在独立品牌名下。本篇按已经走通的实际路径写：在 Spaceship 买域名 DNS 托管到 Cloudflare Cloudflare Pages 一键绑定。无需服务器、无需备案。

本篇只覆盖「静态站 + 自定义域名」这条最常见的高阶路径。如果你要跑后端 / 数据库 / 自建 API 中转，那是另一个话题（需要 VPS + Nginx + 运维），不在本页范围内——而且那条路成本高、运维累，普通人没必要碰。

一、为什么要绑定自己的域名

  • 品牌资产：流量沉淀在你的域名下，将来换平台、换托管商也不丢访客。
  • 更短、更专业：yourname.xyz 比 xxx.pages.dev 好记、好传播。
  • SEO 更友好：搜索引擎对独立域名的收录权重高于 *.pages.dev 这种子域名。
  • 零额外成本：只要花十几块买域名，绑定 Cloudflare Pages 完全免费。

二、第一步：在 Spaceship 买域名

买域名就是花钱把一个名字（如 955827.xyz）租下来，每年续费一次。

推荐：Spaceship（界面干净、价格透明，国内付款友好）

  • 官网：spaceship.com
  • 支持支付宝 / 微信 / 信用卡 / PayPal，国内付款无门槛。
  • 常见 .xyz 后缀首年只要几美元（续费会涨到 10 美元左右），.com 通常 8–10 美元/年。
  • 购买流程：搜想要的域名 加购物车 注册 / 登录 Spaceship 账号 选年限 付款 进后台 Domains 看到已购域名。

备选方案

  • Google Workspace 域名注册：曾有过 11 元/年的 .com 优惠，听起来很香——但必须用国外信用卡 / PayPal 付款，国内单币种卡（含大部分 Visa / Mastercard 借记卡）容易绑卡失败，被反欺诈直接拒。
  • Cloudflare Registrar：成本价注册、无溢价；适合已经在 Cloudflare 生态里、需要简化流程的人。
  • NameSilo / Porkbun / Namecheap：老牌国外注册商，价格实惠、免费 WHOIS 隐私保护（默认挡住你的注册人信息）。

新手首推 .xyz 后缀：便宜、好记、不限制注册人；.com 经典但首年常被「首年特价、续费涨」套路，结算前要看清续费价，别只看首年。

买之前先用搜索引擎查一下这个域名有没有「黑历史」——曾被用于违规站点、灰色行业的域名会影响后续收录和信任度，搜索引擎不一定恢复排名。

三、第二步：DNS 托管到 Cloudflare

买完域名后，DNS 默认在 Spaceship 解析。但 Cloudflare 的 DNS 是免费的、性能更好，还能一键给 Pages 上 HTTPS。所以把域名的「NS 记录」改成 Cloudflare 给你的两个地址，DNS 就由 Cloudflare 管了。

在 Cloudflare 添加站点

  1. 注册 / 登录 Cloudflare

    打开 dash.cloudflare.com，用邮箱注册或登录。

  2. 添加站点

    点 Add a site 输入你刚买的域名（如 yourname.xyz） 选 Free 计划。

  3. Cloudflare 扫描现有解析

    点 Continue，Cloudflare 会自动扫描 Spaceship 已有的解析记录（如 www、@）。先按默认继续，后面绑定 Pages 时 Cloudflare 会自动加正确的 CNAME。

  4. 拿到 Cloudflare 的 NS 记录

    Cloudflare 给你两个 NS 地址（形如 ada.ns.cloudflare.com、bob.ns.cloudflare.com），复制下来。

在 Spaceship 把 NS 改成 Cloudflare

  1. 登录 Spaceship 后台

    在 Domains 列表里找到你的域名 点 Manage。

  2. 修改 Nameservers

    在 Nameservers 项，把默认的 Spaceship NS（形如 ns1.spaceship.com）删掉，填上 Cloudflare 给你的两个 NS 地址。

  3. 保存并等待生效

    通常几分钟到几小时生效。Cloudflare 后台的域名会从 Pending 变成 Active，说明接管成功。

NS 修改是「域名所有权交接」级别的操作——改完后，域名解析完全由 Cloudflare 说了算，Spaceship 这边不再提供 DNS 编辑功能（要加解析记录就得去 Cloudflare）。所以改之前先确认 Cloudflare 已扫到你之前重要的解析记录。

四、第三步：在 Cloudflare Pages 绑定自定义域名

NS 生效后，回到 Cloudflare Pages 控制台，给已有项目加一个 Custom domain 就完事了。

  1. 进入 Pages 项目

    Cloudflare 左侧菜单点 Workers & Pages 选中你已经部署好的 Pages 项目。

  2. 添加自定义域

    点 Custom domains Set up a custom domain，输入 yourname.xyz。建议把 www.yourname.xyz 也一起加上，CF 会自动做重定向。

  3. Cloudflare 自动配置

    由于 DNS 已经在 Cloudflare 托管，它会自动添加 CNAME 解析指向你的 Pages 项目，并自动签发免费证书（Universal SSL）——这两步你什么都不用做。

  4. 等待 + 验证

    几秒到几分钟，状态变成 Active 即可。浏览器打开 https://yourname.xyz 能看到你的站点就成功了。

想强制全部走 HTTPS？在 Cloudflare 域名后台 SSL/TLS 选 Full (Strict)，再开启 Always Use HTTPS，访客输入 http:// 也会被自动 301 到 https://。

配置生效后若页面没更新，请按 Ctrl+F5（Mac：Cmd+Shift+R）硬刷新清除浏览器缓存。

五、成本与常见问题

成本清单（实测一年开销）

域名费用：Spaceship 首年几美元（.xyz 最便宜），续费涨到 10 美元左右 Cloudflare DNS：免费 Cloudflare Pages 托管：免费（个人站根本碰不到付费阈值） SSL 证书：Cloudflare Universal SSL 自动签发，免费 合计：一年只花域名钱，约几十到一百多元人民币

常见问题

  • 需要备案吗？不需要。本方案完全跑在 Cloudflare 全球节点，不涉及中国大陆服务器，没有 ICP 备案要求。
  • 国内访问速度怎么样？Cloudflare 在国内有合作节点（与腾讯、京东等合作），大多数情况下可用；比直接访问 *.pages.dev 略慢但更稳定。如果以国内用户为主、内容合规，再考虑走大陆 CDN。
  • 域名忘了续费会怎样？赎回期通常 30 天，赎回费几百元。建议开 Spaceship 的自动续费，或日历提前 7 天提醒。
  • 想把域名转去别家？可以。Spaceship 域名 60 天解锁期后可转到 Cloudflare Registrar / Namecheap 等，流程不复杂。
  • 想跑后端怎么办？静态站这条路到此为止。要跑后端 API，可以加 Cloudflare Workers（同样免运维、免费额度够用），或者租一台 VPS（需要自己运维 Nginx / 防火墙 / 证书）。普通学习站 / 工具站基本不需要。
  • 一个域名能绑多个 Pages 项目吗？可以，用子域名区分：如 blog.yourname.xyz 给博客、tools.yourname.xyz 给工具站，每个子域名在对应 Pages 项目里绑一次就行。
