# Learn · 现实社会知识图谱 1.0

> **从我出发，向外看城市，向上看国家，向后看历史，向旁看世界。**

---

## 设计原则

- **问题来自生活，答案才进入政治、经济、社会和历史**
- 不追求"知识多"，追求"原来如此"
- 讲结构不做立场，讲概念不做煽动，讲公开事实不做内幕
- 来源优先级： 官方文件/政府网站   权威资料   百科补充
- 每条连接必须答得上"为什么这两个东西真的有关"
- V1 地理范围：**广州 + 深圳**（暂不放京沪），跑通后再扩
- ** 涉敏红线（2026-08-19 定）**：不主动探讨「党 / 政协 / 人大」这类政治主体，在中国当前语境下敏感，不做立场、不做内幕、不展开。感兴趣者自行研究。内容表述落到「政府」这一行政层面即可，准确性优先于回避（如「四套班子 = 党委、人大、政府、政协」这种客观事实性表述可保留，但不展开探讨）。

## 八、内容规范

### 卡片固定结构

```
┌──────────────────────────────┐
│                              │
│    钩子问题（一句话）       │
│                              │
│   ┌──────────────────────┐   │
│   │                      │   │
│   │   知识树（SVG 关系图） │   │
│   │   节点 + 箭头        │   │
│   │                      │   │
│   └──────────────────────┘   │
│                              │
│   1~3 句关键解释             │
│                              │
│   相关：节点A · 节点B · 节点C │
│                              │
│    资料来源：xxx          │
│                              │
└──────────────────────────────┘
```

### 文字比例
- **70% 图**（关系树 / SVG）
- **20% 标签 / 数字**
- **10% 解释**（一句话讲透）

### 来源标识
-  官方文件（中国政府网 / 国务院部委 / 地方政府官网）
-  政府网站
-  权威资料（权威媒体 / 高校研究机构 / 正式出版物）
-  百科补充（仅作概念补充，不作核心依据）

### AI 生成准则
- 先提炼知识结构，再绑定来源
- 无可靠来源的事实不自动作确定结论输出
- 定位 = AI 帮你整理 + 官方资料兜底 + 图谱负责理解

### 红线
- 讲结构不做立场
- 讲概念不做煽动
- 讲公开事实不做未经证实的内幕
- 影视剧只是案例不是证据
- 不为炫技强行建立关联（每条连接必须答得上"为什么有关"）
- 不做"政治知识专栏"——是"制度、社会与现实"

## 九、技术规格

### 数据模型
```json
{
  "id": "unique-id",
  "title": "钩子问题",
  "hook": "反常识/好奇/现实问题",
  "nodes": ["节点A", "节点B", "节点C"],
  "edges": [["节点A", "节点B"], ["节点B", "节点C"]],
  "explanation": "1~3句关键解释",
  "source": { "type": "", "text": "来源描述", "url": "" },
  "related": ["相关卡片ID"],
  "tags": ["分类标签"],
  "tier": "A|B|C|D|E",
  "geo": ["广州", "深圳"]  // V1 只用广深
}
```

### 技术原则
- **不生成图片**（HTML + CSS + SVG 呈现关系感）
- **不依赖后端 / 数据库**（纯静态 JSON）
- **知识结构 JSON 化**，前端 SVG 渲染
- **IndexedDB** 存用户行为（看过/收藏/跳过/兴趣权重/当前路径）
- **零账号**，localStorage + IndexedDB 足够
- 跑在 **Cloudflare Pages** 上
- 内容更新 = 加一条 JSON  GitHub  Pages 生效

### 推荐算法 V1（不需要 AI）
```
score =
  兴趣匹配(70%)      // 用户行为加权
  + 当前节点相关度(20%) // 地图中邻接节点
  + 未看过过滤
  + 随机扰动(10%)     // 探索因子，避免信息茧房
```

### 交互设计
- **上滑** = 看过
- **下滑** = 收藏（进"我的知识"）
- **左滑** = 跳过
- **点击节点** = 深入知识地图（显示附近世界）
- 卡片出现：GSAP 节点逐个浮现  箭头延伸  结论出现
