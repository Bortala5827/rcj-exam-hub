# RCJ Training · 职业能力训练系统（MVP 5.0）

> 低调内测中（优化测试中）。入口不挂任何导航/页脚，仅部署于 `exam.955827.xyz/train`。

## 定位
不是"体测工具 / 标准库"，而是"职业能力训练系统"：把运动科学翻译成用户能执行的东西。
核心：**成长数据才是资产，标准全由用户自定义**（平台零官方数字、零误导风险，永不因标准变化失效）。

## 模块（纯前端 + localStorage，无后端）
- **我的目标**：选"我要成为谁"（辅警 / 消防 / 自定义） 六维能力（心肺 / 力量 / 爆发 / 速度 / 灵敏 / 恢复）逐项自定义目标项。
- **我的测试**：按日期记录单次成绩。
- **成长记录**：能力地图进度条 + 与目标的差距 + 趋势 sparkline。
- **为什么练**：6 张运动生理学知识卡 + 科普免责声明。

## 技术
- 单文件 `index.html`（内联 CSS/JS），无构建步骤、无外部依赖。
- 数据存本机浏览器（localStorage），换设备不自动同步。
- 已注入 RCJ 统一埋点 `site=training`（仅 `955827.xyz` 域触发，不污染本地）。
